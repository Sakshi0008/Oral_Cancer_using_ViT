# Model Checkpoints & Architecture Information

This directory holds trained PyTorch checkpoints for the Vision Transformer model.

## Model Architecture Specifications

- **Backbone**: Vision Transformer (`vit_b_16`)
- **Patch Size**: $16 \times 16$ pixels ($14 \times 14 = 196$ spatial tokens + 1 `[CLS]` token = 197 tokens total)
- **Input Resolution**: $224 \times 224 \times 3$ (RGB)
- **Hidden Dimension**: $D = 768$
- **Transformer Encoder Layers**: 12 Multi-Head Self-Attention Blocks (12 heads each)
- **Classification Head**:
  - `nn.Linear(768, 256)`
  - `nn.ReLU()`
  - `nn.Dropout(p=0.3)` (enables Monte Carlo Dropout sampling during inference)
  - `nn.Linear(256, 3)`
- **Output Classes (3)**:
  - 0: `Normal`
  - 1: `Low Risk of Malignant Transformation`
  - 2: `High Risk of Malignant Transformation`

## Saved Weights File

- `models/best_vit_model.pth`: Generated by `python ml/train.py` upon achieving the highest validation macro F1-score.
- When running in **Demo Mode** without running full training, the system initializes the transfer-learning architecture with default pretrained weights and displays appropriate status.
